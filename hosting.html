Launch Campus Market online Deploy this app as a production web service with persistent storage.
Recommended platform

Render is a straightforward choice for this Node.js app. The included deployment template wires up the build command, start command, and persistent storage.

Deploy steps
  1. Connect this repository to Render or any Node.js host.
  2. Use npm start as the start command.
  3. Set CAMPUS_MARKET_DATA_DIR to a persistent writable directory.
  4. Create an admin account with the setup script after deployment.
